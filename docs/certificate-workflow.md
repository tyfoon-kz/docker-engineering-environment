# Certificate Workflow

Local certificates are generated by:

- `bin/generate-local-certs.sh`

The script creates:
- `docker/traefik/certs/localho.st.crt`
- `docker/traefik/certs/localho.st.key`

Traefik loads them through:
- `docker/traefik/dynamic/tls.yml`

This keeps the HTTPS setup reproducible:
- another developer can generate the same local certificate bundle;
- the repository documents where the certificate comes from;
- Traefik does not depend on a mysterious manual step.
